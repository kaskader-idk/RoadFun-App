RoadFun soll eine app sein für fahrer, und leuten die lust auf zeitfahren und so haben.
Es soll eine android version, ios version und eine webversion geben (Für den anfang ohne Android).
Jede app reded mit einem backend server (in C# codiert) welche die daten in eine .mdf datei speichert.

Händyversion und Web version sollen genau die selben funktionen haben:
  eine Karte (wie apple maps) mit straßen und einem auto in der mitte (User). Es soll möglich sein routen planen zu können und (wie in apple maps) soll angezeigt werden wann man ankommt (zeit und km), man soll auswählen können ob man eher eine lustige route (für fahrenthusiasts), sparsame route (eco), die schnellste oder die kürzeste haben will. 

Ein feature dieser app soll sein, polizei sichtungen, blitzer (mobile und stationäre), staus und gefahren melden zu könnnen, was dann auf der karte angezeigt wird mit einem roten kreis (sowas wie in forza horizon diese fliegenden festivals). bei blitzern kann man die ricthung in die sie schauen auswählen können. 

Noch ein feature soll sein, das man strecken auswählen sollen kann, bei dennen man sich dann per Zeit messen kann. Man soll auf der karte den start und das ende auswählen können und dann auswählen können das beim reinfachren in die strecke die zeitmessung beginnen soll, und am ende der strecke die zeitmessung stoppen soll. Beim fahren der strecke sollen auf infos wie g-kräfte, höchstgeschwindigkeik, durchschnitte und so weite notiert werden und am ende angezeigt. Ein besondere feature soll sein, das man sich die strecke genauer anschauen können soll, mit inklusive höchendaten (3d ansicht mit 360° view) und das man die umgebung ein und auschalten kann. 

Car meets sollen auf veanschtaltet werden können per app. wenn man auf der karte einen ört auswählt und ihn dort dann eintragt. 

Bei der app soll es auch ein profil geben, zum anmelden und mit daten über den besitzer (name alter auto usw) mit pfp. 

diese dinge sollen auf dem server geschpeichert werden sodas man dann auf diese zugreifen kann.

Es soll einen Admin account geben : name "Admin", psw "123321" der dann alle fahrer auf der karte sehen kann.

es soll möglich sein mit anderen fahrer sich zu befreunden per code der an jedem profil steht (sowas wie discord). Miteinander schreiben soll möglich sein (per server oder nicht kannst du entscheiden).



Das soll keine öffentliche app sein, sondern nur für mich und meine freunde. falls etwas nicht legal sein sollte oder du etwas nicht darfst, gibt es einfach in eine "DARFNICHT.md" datei rein, und dann schau ich es mir an.
